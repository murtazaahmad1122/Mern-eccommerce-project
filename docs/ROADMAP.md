# Engineering Roadmap

## Phase 1 — Portfolio release

- [x] Three-application monorepo
- [x] Environment-based API configuration
- [x] JWT authentication and role authorization
- [x] Swagger documentation
- [x] Deployment configuration and CI
- [ ] Publish cloud URLs and screenshots
- [ ] Load a curated synthetic demo catalog

## Phase 2 — Reliability and security

- [ ] Backend integration tests with an isolated database
- [ ] Frontend component and critical-flow tests
- [ ] Consistent request validation and error contracts
- [ ] Helmet security headers and rate limiting
- [ ] Rotating refresh tokens, email verification, and password reset
- [ ] Structured logs, correlation IDs, and error monitoring

## Phase 3 — Cloud delivery

- [ ] Durable object storage and responsive image variants
- [ ] Docker and local Compose orchestration
- [ ] Preview smoke tests, dependency scanning, and secret scanning
- [ ] Database backup and recovery documentation

## Phase 4 — Commerce depth

- [ ] Inventory reservations and transaction-safe checkout
- [ ] Refunds, cancellations, and webhook idempotency
- [ ] Shipment tracking and notifications
- [ ] Product variants, taxes, and regional shipping
- [ ] Analytics, audit trails, accessibility, and performance budgets

Items are separated from implemented features so reviewers can distinguish current
engineering work from planned improvements.
